## Career Radar v1.2.2 — Source Health & Release Durability

v1.2.2 is a reliability and security patch focused on keeping scheduled source-health checks and packaged releases healthy as registry snapshots age.

### Fixed

- **Source health retry bootstrap** — scheduled health retries now bootstrap from the rolling `market-data/source-registry.latest.json` publication instead of a checked-in snapshot that naturally becomes stale.
- **Freshness safety preserved** — live rolling snapshots still enforce the normal freshness guard; only the immutable packaged/offline fallback is exempt from wall-clock age checks while retaining schema and minimum-source validation.
- **Windows packaged fallback** — first-run/offline recovery can safely use the validated bundled registry after release age exceeds the live snapshot freshness window.
- **Frontend dependency security** — the lockfile was refreshed to remove the high/critical advisories found in the prior dependency graph, including the affected Next.js/js-yaml/sharp chain.
- **Regression protection** — tests now pin the source-health workflow to the rolling registry path and cover the intended live-vs-packaged snapshot semantics.

### Validation

The release is gated on the repository's complete CI matrix, security audits, PostgreSQL integration, live ATS ingestion/browser E2E, acceptance/performance checks, and the Windows installer/portable runtime smoke tests. A dedicated source-health smoke also bootstraps the current rolling `market-data` registry before this release request is prepared.
