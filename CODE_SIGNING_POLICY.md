# Code signing policy

Career Radar publishes Windows binaries from the public source repository at:

- https://github.com/MahdiNavaei/Europe-Visa-Sponsorship-Jobs

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

## Scope

Only official Career Radar Windows release artifacts built from this repository may be submitted for signing. The signing workflow must build on GitHub-hosted runners from repository-controlled workflow files and must preserve source/build provenance.

The signed release surface is:

- `CareerRadar.exe`, the self-contained desktop launcher included in both installer and portable packages.
- `CareerRadar-Setup-v<version>.exe`, the official Windows installer.

The workflow supports two truthful release modes. A `SIGNED` release uses Authenticode
when both signing secrets are configured and verifies both executables. An `UNSIGNED`
release is allowed when both signing secrets are absent; it preserves all package,
smoke-test, manifest, and SHA-256 gates and clearly warns users that SmartScreen may
show an unknown-publisher message. A partially configured secret pair or any signing
failure fails the workflow; it never falls back to unsigned mode.

## Build and signing rules

1. Release binaries are built from a repository commit by GitHub Actions on GitHub-hosted runners.
2. Release source, build scripts, dependency locks, packaging scripts and signing workflow are version controlled in this repository.
3. The tagged release commit must pass the repository's release gates before publication.
4. Signing credentials or private signing keys are never committed to the repository.
5. SignPath origin verification is used for Foundation-backed signing. The SignPath private key remains outside the build runner.
6. A signing request is only made for artifacts generated by the same workflow run and commit that is being released.
7. The workflow verifies Authenticode after signing and verifies SHA-256 checksums before release publication.
8. The project does not sign third-party projects or arbitrary user-supplied binaries.

## Privacy

Career Radar's privacy behavior is documented in [`PRIVACY.md`](PRIVACY.md).

The desktop application keeps candidate profile data, saved jobs, application state and notes on the user's local machine. It does not upload that personal profile data to a Career Radar-operated service. Background network activity is limited to obtaining public market/catalog data and public ATS job data needed for the product, plus destinations explicitly opened by the user.

## Reporting

Security concerns about a release or suspected signing-policy violation should be reported through the repository's security/contact channels before public disclosure where practical.
